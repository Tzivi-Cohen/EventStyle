## בדיקות ידניות שבוצעו

- הפעלת השרת במצב פיתוח ובדיקה ידנית עם curl: Health, חבילות, Swagger UI וקבצי ה־JS שלו, התחברות עם אימייל באותיות גדולות ורווחים, וחיפוש בעברית עם מיון לפי תקציב.
- **סימולציה של פריסה ל־Render:** הרצת `npm run start:render` עם `NODE_ENV=production` על מסד ריק. בדקתי ש:
  - ה־Migrations הוחלו וה־Seed רץ.
  - השרת עלה, ו־Health ו־Swagger החזירו 200.
  - סיסמת הפיתוח `Admin12345` **נדחתה**, ורק הסיסמה מ־`SEED_ADMIN_PASSWORD` עבדה.
  - בלי `SEED_CLIENT_PASSWORD` לא נוצרו לקוחות הדגמה.

## מה לא נבדק בפועל (דורש חשבונות חיצוניים)

- **שליחת מייל אמיתית:** לא רלוונטי. Brevo הוסר, ואין שירות מיילים חיצוני. קוד האימות מודפס ביומן השרת, ובבדיקות נעשה שימוש בשירות מיילים מדומה.
- **העלאה אמיתית ל־Cloudinary:** בבדיקות השתמשתי באחסון מדומה. כל הלוגיקה סביב ההעלאה נבדקה: הרשאות, סוג קובץ, גודל קובץ ושמירה במסד הנתונים.
- **פריסה בפועל ל־Render ו־Neon:** נבדקה רק בסימולציה מקומית.

אחרי שתגדירי את החשבונות, אפשר לבדוק את שני השירותים דרך Swagger: הרשמה עם האימייל האמיתי שלך, והעלאת תמונה לגלריה.
